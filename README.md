# QuickMaths 🚀

A high-fidelity, majestic mental math training platform specially tailored for high school students.

## ✨ Features
- **Majestic Galaxy Aesthetic**: Immersive space-depth UI with layered starfields and nebulae.
- **Standalone Diagnostic Test**: Progressive 15-question test calculating a weighted score (70% Accuracy, 30% Speed).
- **Professional Dashboard**: Personalized Learning, Daily Practice, and Global Competition.
- **Side-by-Side Analytics**: Detailed performance breakdown with rank reveal.

## 🛠️ Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, JavaScript.
- **Design**: Glassmorphism, CSS Animations, Responsive Layout.

## 🚀 Getting Started
1. Clone the repository.
2. Open `index.html` in your browser or use a live server (e.g., `npx serve .`).
